# Extended Family Integrated Services, LLC

Responsive static website. Open `index.html` to view locally.

## Hosting
Enable GitHub Pages from the `main` branch and `/ (root)` folder. Connect `extendedfamilyintegratedservices.com` after configuring DNS.

## Contact
There is no contact form. The Contact section offers a `mailto:` link plus Gmail, Outlook, and Yahoo Mail compose links so visitors can email from the app they choose.

## Assets
The assets directory includes business cards, brochures, QR codes, and vCard contact downloads. QR codes point to the custom domain.
